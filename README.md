# MLP 学习与训练可视化实验室

一个围绕**多层感知机（MLP）训练过程**的纯前端项目，包含两个可直接运行的工具：

1. **训练可视化工具**（项目根目录）：交互式观察 MLP 训练时权重、偏置、梯度、损失和决策边界的变化。
2. **闯关学习游戏**（`mlp-game/`）：把核心知识点转化为 5 个关卡，通过操作、即时反馈、得分和星级帮助用户逐步理解。

两个工具均无外部依赖，不需要安装或构建，直接用现代浏览器打开对应目录下的 `index.html` 即可。

---

## 一、训练可视化工具

打开根目录的 `index.html`。

### 主要功能

- **网络结构图**：节点颜色表示激活值，连线按权重或激活贡献着色，可高亮当前样本的主导前向传播路径。
- **前向传播演示**：选择样本后逐层播放计算过程，显示每层的线性组合与激活值。
- **权重与偏置**：各层权重热力图、偏置数值条；点击任意参数可查看其取值轨迹。
- **梯度与更新**：梯度热力图、各层参数更新量 `‖ΔW‖` 随轮次的变化曲线，以及单个参数的 `Δ = −η·g` 明细。
- **损失与准确率曲线**：训练全过程的交叉熵损失与准确率，带当前轮次游标。
- **决策边界**：实时显示网络对样本空间的分类结果，点击图中数据点可切换观察样本。
- **可调参数**：数据集、隐藏层数、每层神经元数、学习率、训练轮数、激活函数；支持重新训练、播放/暂停、单步和轮次拖动。

> 训练采用全批量梯度下降，数据使用固定随机种子，因此相同参数下结果可复现。

## 二、MLP 闯关学习游戏

打开 `mlp-game/index.html`，点击「开始挑战」。

### 关卡设计

| 关卡 | 知识点 | 挑战内容 | 通关条件 |
| --- | --- | --- | --- |
| 1 | 前向传播 | 按 输入层 → 隐藏层 → 输出层 顺序点亮节点，并选出预测值 | 完成 2 个样本 |
| 2 | 权重与偏置 | 拖动 w₁、w₂、b 调整分界线 | 6 个点全部分类正确，且最小间隔 > 0.12 |
| 3 | 学习率 | 根据损失曲线和梯度选择学习率 | 一轮更新把损失降到 0.05 以下，共 3 轮 |
| 4 | 梯度方向 | 在损失等高线图里找出负梯度方向 | 连续 3 轮选对 |
| 5 | 完整训练 | 配置网络容量、学习率和训练轮数，真实训练 MLP | 准确率 ≥ 90% |

### 机制

- 首次答对得分最高，重试后得分递减；每关按重试次数评 1–3 星并给予星级奖励。
- 顶部进度条与星级实时更新；通关后展示总分、勋章和各关明细，可重新挑战。
- 第五关内置与可视化工具一致的训练算法（tanh + sigmoid + 二元交叉熵 + 全批量梯度下降）。

## 四、运行方式

### 直接打开

双击 `index.html` 或 `mlp-game/index.html` 即可，无需服务器。

### 本地静态服务（可选）

在项目根目录执行：

```bash
python -m http.server 8000
```

然后访问：

- 可视化工具：<http://localhost:8000/index.html>
- 闯关游戏：<http://localhost:8000/mlp-game/index.html>

## 五、技术实现

- 原生 HTML / CSS / JavaScript，无框架、无第三方库、无构建步骤。
- 可视化使用 SVG 与 Canvas；训练与反向传播在浏览器本地计算。
- 数据使用固定种子的伪随机数生成，保证可复现。
- 兼容支持现代 Web 标准的桌面浏览器（Chrome / Edge / Firefox / Safari）。
